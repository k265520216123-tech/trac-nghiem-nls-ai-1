# Trắc nghiệm Năng lực số và ứng dụng AI

Trang làm bài 200 câu, chạy hoàn toàn trên trình duyệt (không cần máy chủ).

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub (ví dụ `trac-nghiem-nls-ai`), để chế độ Public.
2. Bấm **Add file → Upload files**, kéo `index.html` (và `README.md`) vào, bấm **Commit changes**.
3. Vào **Settings → Pages**. Ở mục *Build and deployment*, chọn **Deploy from a branch**, branch `main`, thư mục `/ (root)`, bấm **Save**.
4. Đợi 1–2 phút, link có dạng `https://<tên-tài-khoản>.github.io/trac-nghiem-nls-ai/`.

Bài làm sai được lưu trong trình duyệt của từng người (localStorage), có thể làm lại riêng các câu sai.
